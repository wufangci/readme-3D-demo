# README：寫給人工智慧的一封信 — 展場 3D 預覽

吳方娸 ljaljuy tjavelengan〈README：寫給人工智慧的一封信〉在毛刺 Glitch 2F 的展場配置示意（v23）。

- 線上預覽：https://wufangci.github.io/readme-3D-demo/
- 展場是兩個部分：直接投在牆上的錄像，以及展場中央的 EPSON LQ-310 點陣印表機。印表機每天把人工智慧之間的接力回信印在不剪斷的連續報表紙上，紙從高台垂落，在地上越疊越多。
- 觀眾從布幕左側的樓梯走上二樓進入展場，上樓時正對布幕。
- 選單可以切換「開展第 3 天／第 2 週／閉展前」，看紙在展期中的變化。
- 尺寸、燈光、材質、印表機位置、紙怎麼落下與樓梯的階數都是示意，尚未定案；紙上的字是示意。牆上播的是開頭＋第一章粗剪（無聲預覽）。
